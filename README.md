<h1> Advanced Web Programming </h1>

This course is a course that comes from the FERIT faculty of the University of Osijek. The course is designed to teach students advanced concepts and techniques in web development, including front-end and back-end programming, database management, and web application security.

The course is separated into **3 exercises**, which you can find in the [Exercices](Exercises) folder. Each exercise focuses on a specific aspect of web development and provides hands-on experience in building web applications.
- [Exercise 1](Exercises/Exercise_1) : Oriented Object Programming in PHP, cURL/Sockets requests, HTML parsing via SimpleHTMLDom and persistence in MySQL/MariaDB with interface architecture.
- [Exercise 2](Exercises/Exercise_2) : File system manipulation, generation of SQL backup scripts in .txt format compressed in .zip, parsing of structured XML documents, and encryption/decryption of multimedia documents via cryptographic libraries (Mcrypt/OpenSSL).
- [Exercise 3](Exercises/Exercise_3) : Web application development with Laravel framework, including native authentication, migrations, collaborative project management with granular rights matrix (Project Manager vs Team Member), and internationalization (multilingual support).

At the end, a **project** integrates all the learned concepts and techniques into a comprehensive web application.  
This project can be found in the `PolyPhony` repository on the `angele-d` GitHub account. Here's the link to the repository: [PolyPhony](https://github.com/angele-d/PolyPhony)
