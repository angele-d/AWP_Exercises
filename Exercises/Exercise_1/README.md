# Exercise 1 — Advanced Web Programming

## Description

This project scrapes graduate thesis pages from the FERIT website, creates `GraduateThesis` objects from the extracted data, and stores the theses in a MariaDB/MySQL database.

The scraper processes pages 2 to 6 of:

`https://stup.ferit.hr/zavrsni-radovi/page/{number}/`

For each thesis, the program extracts:

- `work_name` — thesis title
- `work_text` — thesis content
- `work_link` — thesis URL
- `identification_number` — identifier extracted from the thesis image filename

The data is stored in the `graduate_theses` table.

---

## Requirements

The project requires:

- PHP 8.x
- MariaDB/MySQL
- Composer
- PHP cURL extension
- PHP PDO MySQL extension

On Debian/Ubuntu, the main packages can be installed with:

```bash
sudo apt update
sudo apt install php php-cli php-curl php-mysql mariadb-server mariadb-client composer
```

Check the installations:

```bash
php --version
composer --version
```

## Installation

Clone the repository and enter the project directory.

Install the Composer dependencies:

```bash
composer install
```

This installs the libraries listed in `composer.json`, including:

- `simplehtmldom/simplehtmldom`
- `vlucas/phpdotenv`

The `vendor/` directory is generated by Composer and should not be committed to Git.

---

## Database setup

The application uses a MariaDB/MySQL database named:

```text
thesis
```

The required table is:

```text
graduate_theses
```

with the following columns:

| Column | Type | Constraints |
|---|---|---|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT |
| `work_name` | TEXT | NOT NULL |
| `work_text` | LONGTEXT | nullable |
| `work_link` | TEXT | NOT NULL |
| `identification_number` | BIGINT | NOT NULL, UNIQUE |

The `UNIQUE` constraint on `identification_number` prevents the same thesis from being inserted more than once.

The complete database structure can also be restored from the `database.sql` file.

---

## Database credentials

Database credentials are stored in a `.env` file at the root of the project.

Create `.env` from `.env.example`:

```bash
cp .env.example .env
```

Then edit `.env`:

```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=thesis
DB_USERNAME=YOUR_USERNAME
DB_PASSWORD=YOUR_PASSWORD
```

Replace `YOUR_USERNAME` with the username of the MariaDB user used by the project and `YOUR_PASSWORD` with the password of the MariaDB user used by the project.

**Never commit `.env` to Git.**

The `.env` file should be listed in `.gitignore`.

---

## Running the scraper

Once the database and `.env` file are configured:

```bash
php scraper.php
```

The scraper will:

1. Fetch pages 2 to 6 from the FERIT website.
2. Parse the HTML.
3. Extract the thesis information.
4. Visit each thesis page to retrieve its text.
5. Create a `GraduateThesis` object.
6. Save the thesis to MariaDB.

If a thesis page cannot be fetched, the scraper reports the error and continues with the next thesis.

The scraper uses a cURL timeout *(60 secondes)* so that a non-responsive page does not block the program indefinitely.

---

## Database access

The database connection is implemented in `database.php`.

It loads the `.env` file and creates a PDO connection:

```text
PHP → PDO → MariaDB → thesis
```

`GraduateThesis::save()` is responsible for inserting/updating thesis data.

`GraduateThesis::read()` retrieves all theses stored in `graduate_theses`.

## Restoring the database

To recreate the database on another machine:

1. Install MariaDB/MySQL.
2. Create the `thesis` database.
3. Import `database.sql`.
4. Create/configure a MariaDB user with access to the database.
5. Configure `.env`.
6. Run:

```bash
composer install
```

7. Run the scraper:

```bash
php scraper.php
```

---

## Important notes

The scraper depends on the FERIT website being reachable. A thesis page can occasionally be slow or unavailable. A timeout for one page does not necessarily mean that the scraper itself is broken.

If the website changes its HTML structure, the selectors used by the scraper may also need to be updated.
